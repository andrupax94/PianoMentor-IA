# [B-029] Control de MIDIs por usuario y subidas anónimas

**Estado:** pendiente; reservada para el final del MVP.

## Resumen

Definir quién ve cada MIDI: todo el usuario ve el corpus, y cada usuario solo ve sus propias subidas. Decidir qué ocurre con las subidas de un usuario anónimo (hoy todas lo son, `owner_id = NULL`): eliminarlas o promoverlas a cache y, si procede, al corpus.

## Objetivo

Que la biblioteca de piezas tenga un sentido claro cuando haya cuentas: el corpus es común, las subidas son personales, y no queda contenido huérfano sin dueño ni criterio.

## Alcance

- Autenticación mínima y `owner_id` real en las subidas (la columna ya existe desde B-028, `NULL` = anónimo).
- Filtro de visibilidad: `source='corpus'` visible para todos; `source='upload'` visible solo con `owner_id` del usuario (o anónimas, según la decisión).
- Decisión y aplicación sobre las subidas anónimas: borrarlas tras la sesión, conservarlas como cache o promoverlas a corpus.
- Listado de piezas que respete el filtro (cuando exista el endpoint de listado).

## Fuera de alcance

- Perfiles de usuario, roles y recuperación de contraseña más allá de lo mínimo para asociar piezas.
- Detección de duplicados por hash: ya resuelta en B-028.
- Cache de resultados de normalización/evaluación.

## Criterios de aceptación

- [ ] Un usuario autenticado solo ve sus propias subidas y todo el corpus.
- [ ] Las subidas quedan asociadas a `owner_id` en la BD.
- [ ] Existe una decisión documentada para las subidas anónimas y se aplica.
- [ ] Ninguna pieza del corpus se pierde ni se marca erróneamente como de un usuario.
- [ ] Tests de visibilidad y del criterio de subidas anónimas.
- [ ] El flujo completo sigue funcionando en Docker.

## Dependencias

Depende de **B-028** (`owner_id` y `source`) y conviene planificarla después de **B-012** (sesiones), cuando exista ya un listado de piezas que filtrar.

## Evidencia esperada

- Decisión sobre subidas anónimas escrita en esta issue y reflejada en `PLAN.md`.
- Filtro de visibilidad implementado y cubierto por tests.
