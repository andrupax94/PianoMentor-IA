# [U-008.1] Foto de perfil en UserAvatar

**Estado:** implementado (frontend).

## Resumen

Mostrar la foto de perfil del usuario en el círculo `UserAvatar` del `AuthUserMenu` cuando exista (Google o BD).

## Cambios

- `UserAvatar` acepta prop `src` (URL de foto) y renderiza `<img>` cuando existe; si no, inicial.
- `AuthUserMenu` pasa `user?.picture` a `UserAvatar`.
- Estilo `object-fit: cover` para que la foto llene el círculo.

## Criterios de aceptación

- [x] Con sesión y foto disponible, `UserAvatar` muestra la imagen.
- [x] Sin foto, se muestra la inicial como antes.
