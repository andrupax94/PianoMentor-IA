# [U-008] Foto de perfil, biblioteca de piezas por usuario y bienvenida personalizada del chatbot

**Estado:** definido; pendiente de implementar.

## Resumen

Tres mejoras de personalización y acceso al catálogo: (1) mostrar la foto de perfil del usuario (Google o guardada en BD) en el `UserAvatar` del `AuthUserMenu`; (2) añadir una tabla de biblioteca de piezas visible por usuario, con reglas de visibilidad por cuenta y por estado de sesión; (3) hacer que el chatbot muestre un mensaje de bienvenida con el nombre del usuario cuando haya iniciado sesión y usar ese nombre en el prompt básico del backend.

## Objetivo

Que la app refleje la identidad del usuario (foto y nombre) y ofrezca un catálogo de piezas adecuado a su nivel/cuenta, sin quitar las piezas por defecto al iniciar sesión.

## Alcance

### 1. Foto de perfil en `UserAvatar` (`AuthUserMenu`)

- Almacenar y usar la URL de foto de perfil del usuario cuando inicie sesión con Google.
- Si el usuario tiene foto guardada en la BD, usar esa.
- Cuando un usuario tiene foto, mostrarla en el círculo `UserAvatar` dentro de `AuthUserMenu`.
- Prioridad: foto de Google al iniciar sesión; si existe foto en BD, usar la de BD.

### 2. Biblioteca de piezas por usuario (tabla en BD)

- Agregar una tabla en la BD de piezas de la biblioteca que el usuario puede ver.
- **Sin iniciar sesión:** la app solo muestra piezas de nivel "principiante", quitando adicionalmente la "pieza de práctica".
- **Con `palenciadj94@gmail.com`:** aparecen todas las piezas excepto "pieza de práctica".
- **Con `eduardoandresp94@gmail.com`:** aparece "Pieza de práctica".
- Las piezas visibles sin iniciar sesión también vienen incluidas para los usuarios que sí inician sesión.
- Iniciar sesión añade más piezas; no quita las por defecto.

### 3. Mensaje de bienvenida y prompt del chatbot

- El chatbot muestra un mensaje de bienvenida con el nombre del usuario cuando este haya iniciado sesión.
- Modificar el prompt básico del chatbot en el backend para que use el nombre de la persona.
- Si no hay sesión iniciada, el prompt se mantiene como está actualmente.

## Fuera de alcance

- Cambio de foto de perfil desde la app (edición de perfil).
- Gestión administrativa de la tabla de biblioteca fuera de las reglas descritas.
- Otros proveedores de login distintos de Google.

## Criterios de aceptación

- [ ] La URL de foto de perfil se almacena y se usa al iniciar sesión con Google y cuando exista foto en BD.
- [ ] El `UserAvatar` del `AuthUserMenu` muestra la foto cuando el usuario la tiene.
- [ ] Existe una tabla en BD para las piezas de la biblioteca visibles por usuario.
- [ ] Sin sesión, solo se muestran piezas de "principiante" (sin "pieza de práctica").
- [ ] Con `palenciadj94@gmail.com` se muestran todas las piezas excepto "pieza de práctica".
- [ ] Con `eduardoandresp94@gmail.com` se muestra "Pieza de práctica".
- [ ] Las piezas visibles sin sesión se incluyen también para usuarios con sesión.
- [ ] Iniciar sesión añade piezas sin quitar las por defecto.
- [ ] El chatbot muestra mensaje de bienvenida con el nombre del usuario al iniciar sesión.
- [ ] El prompt básico del chatbot en el backend usa el nombre de la persona cuando hay sesión; sin sesión se mantiene igual.

## Dependencias

- **U-005 / U-006 / U-007**: autenticación, tabla `users` y vinculación con Google.
- Catálogo de piezas existente y nivel de dificultad.
