# [U-008.3] Mensaje de bienvenida y nombre del usuario en el chatbot

**Estado:** implementado (backend: user_name en prompt y bienvenida; frontend: token en sendAgentMessage y bienvenida en MentorChat).

## Resumen

El chat del mentor muestra un mensaje de bienvenida con el nombre del usuario cuando hay sesión iniciada, y el prompt básico del backend usa el nombre de la persona.

## Cambios

### Backend (`chat.py`)
- `ChatService.run()` acepta `user_name` opcional.
- `_build_messages()` incluye el nombre en el system prompt cuando hay sesión.
- Si el `chat_id` es nuevo y hay `user_name`, se guarda un mensaje de bienvenida como primer mensaje del asistente.

### Backend (`api.py`)
- `POST /agent/chat` acepta header `Authorization`.
- Resuelve el usuario desde el token y extrae el nombre.
- Pasa `user_name` al servicio de chat.

### Frontend (`api-client.ts`)
- `sendAgentMessage` acepta `accessToken` opcional y envía `Authorization: Bearer`.

### Frontend (`MentorChat.tsx`)
- Obtiene la sesión (`/api/auth/session`) al montar.
- Si hay usuario y el chat es nuevo, muestra el mensaje de bienvenida con el nombre.
- Pasa el token al enviar mensajes al chat.

## Criterios de aceptación

- [ ] Con sesión iniciada, el chat muestra "¡Hola <nombre>! ..." al abrirse.
- [ ] El system prompt del backend incluye el nombre del usuario cuando hay sesión.
- [ ] Sin sesión, el prompt se mantiene como está actualmente.
- [ ] El frontend envía el token de autorización al endpoint `/agent/chat`.
