# [B-001.6] Preparar Docker Compose y contextos de build

## Descripción

Permitir construir y ejecutar backend y frontend desde la raíz del proyecto con Docker Compose.

## Archivos esperados

```text
docker-compose.yml
backend/Dockerfile
frontend/Dockerfile
```

## Servicios iniciales

```text
backend  → puerto 8000
frontend → puerto 3000
```

## Criterios de aceptación

- [x] `docker-compose.yml` tiene sintaxis válida.
- [x] Backend y frontend tienen servicios definidos.
- [x] Los contextos de build son correctos.
- [x] Los Dockerfiles no copian archivos fuera de su contexto.
- [x] Los puertos están correctamente expuestos.
- [x] Los volúmenes de datos están definidos cuando corresponda.
- [x] Los servicios comparten una red de Compose.
- [x] El frontend puede resolver la configuración del backend.
- [x] No se copian secretos dentro de las imágenes.

## Dependencias

Depende de **B-001.2**, **B-001.3**, **B-001.4** y **B-001.5**.

## Evidencia de cierre

```powershell
docker compose config -q
→ COMPOSE CONFIG OK

docker compose up -d
→ backend Healthy
→ frontend Started

docker compose ps
→ backend Up (healthy), 0.0.0.0:8000->8000/tcp
→ frontend Up, 0.0.0.0:3000->3000/tcp

Invoke-WebRequest http://localhost:8000/health -UseBasicParsing
→ StatusCode 200
→ {"status":"ok","service":"PianoMentor AI"}

Invoke-WebRequest http://localhost:3000 -UseBasicParsing
→ StatusCode 200
→ página Next.js servida correctamente
```

La evidencia de arranque confirma que las imágenes pudieron ejecutarse correctamente y que ambos servicios están disponibles desde los puertos publicados.
