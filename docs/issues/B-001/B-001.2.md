# [B-001.2] Preparar la configuración inicial del backend

## Descripción

Dejar preparado el backend Python/FastAPI para crecer por módulos y poder ejecutarse localmente o dentro de Docker.

## Archivos esperados

```text
backend/pyproject.toml
backend/Dockerfile
backend/src/piano_mentor/__init__.py
backend/src/piano_mentor/main.py
backend/tests/
```

## Criterios de aceptación

- [x] El paquete `piano_mentor` puede importarse correctamente.
- [x] Las dependencias están declaradas en `pyproject.toml`.
- [x] FastAPI y Uvicorn están configurados.
- [x] Existe un punto de entrada claro para la aplicación.
- [x] Existe una carpeta preparada para tests.
- [x] El backend no depende directamente del frontend.
- [x] El Dockerfile contiene el contexto y el comando necesarios para construir y arrancar la imagen del backend.
- [x] La sintaxis pasa `python -m compileall backend/src backend/tests`.

## Dependencias

Depende de **B-001.1**.

## Evidencia de cierre

Validación ejecutada después de instalar el paquete en modo editable con sus dependencias de desarrollo:

```text
python -m pip install -e ".[dev]"
→ instalación completada correctamente

python -m pytest -q
→ 4 passed

python -m compileall src tests
→ compilación completada correctamente

python -c "from piano_mentor.main import app; print(app.title)"
→ PianoMentor AI
```

Comando de arranque previsto:

```powershell
uvicorn piano_mentor.main:app --host 0.0.0.0 --port 8000
```

El Dockerfile define `PYTHONPATH=/app/src`, instala el paquete desde `pyproject.toml`, expone el puerto `8000` y utiliza el comando de arranque anterior. El build y arranque efectivo de Docker se validarán conjuntamente en B-001.6 y B-001.8.
