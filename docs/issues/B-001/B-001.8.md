# [B-001.8] Validar la estructura completa

## Descripción

Comprobar que la estructura inicial, backend, frontend, datos y Docker funcionan conjuntamente.

## Criterios de aceptación

- [x] `docker compose config` finaliza correctamente.
- [x] La imagen del backend se construye.
- [x] La imagen del frontend se construye.
- [x] Los contenedores arrancan correctamente.
- [x] El frontend responde en `http://localhost:3000`.
- [x] El backend responde en `http://localhost:8000`.
- [x] No existen errores de importación Python.
- [x] No existen errores de compilación TypeScript.
- [x] Los directorios de datos están disponibles.
- [x] El frontend puede comunicarse con el backend mediante la configuración HTTP/WebSocket de Compose.
- [x] Los tests iniciales pueden ejecutarse.
- [x] No quedan rutas incorrectas ni referencias a archivos inexistentes.

## Dependencias

Depende de **B-001.2** a **B-001.7**.

## Validación sugerida

```powershell
docker compose config
docker compose build
docker compose up
python -m compileall backend/src backend/tests
```

Si ya existe el endpoint:

```powershell
curl http://localhost:8000/health
```

## Evidencia de cierre

Validaciones Docker aportadas desde el entorno local:

```text
docker compose config -q
→ COMPOSE CONFIG OK

docker compose up -d
→ backend Healthy
→ frontend Started

docker compose ps
→ backend Up (healthy), 0.0.0.0:8000->8000/tcp
→ frontend Up, 0.0.0.0:3000->3000/tcp

Invoke-WebRequest http://localhost:8000/health -UseBasicParsing
→ StatusCode 200

Invoke-WebRequest http://localhost:3000 -UseBasicParsing
→ StatusCode 200
```

Validaciones locales adicionales:

```text
python -m compileall -q backend/src backend/tests
→ PYTHON COMPILE OK

python -c "import json; json.load(open('shared/schemas/action.schema.json', encoding='utf-8'))"
→ JSON OK

data/midi, data/uploads, data/sessions
→ DIR OK

npm run build
→ compilación Next.js y TypeScript correcta
→ rutas generadas: /, /_not-found y /practice/[sessionId]

python -m pytest -q backend/tests -x
→ 4 passed
```
