# [B-001.4] Crear carpetas de datos y esquemas compartidos

## Descripción

Separar los datos temporales del código y preparar los contratos compartidos entre backend y frontend.

## Estructura esperada

```text
data/midi/
data/uploads/
data/sessions/
shared/schemas/
shared/schemas/action.schema.json
```

## Criterios de aceptación

- [x] Los archivos MIDI tienen una ubicación definida.
- [x] Las cargas temporales están separadas.
- [x] Las sesiones de práctica tienen una carpeta propia.
- [x] Los esquemas están fuera de `backend/` y `frontend/`.
- [x] `action.schema.json` es JSON válido.
- [x] Python puede leer el esquema usando UTF-8.
- [x] No se almacenan archivos privados dentro del repositorio.
- [x] El contrato permite evolucionar sin acoplar directamente las capas.

## Dependencias

Depende de **B-001.1**. Puede coordinarse con **B-001.2** y **B-001.3**.

## Evidencia de cierre

```powershell
python -c "import json; p='shared/schemas/action.schema.json'; data=json.load(open(p, encoding='utf-8')); print('JSON OK'); print(data['title'])"
→ JSON OK
→ PianoMentorAgentAction
```

Estructura comprobada:

```text
data/midi/.gitkeep
data/uploads/.gitkeep
data/sessions/.gitkeep
shared/schemas/action.schema.json
```

Los tres `.gitkeep` están versionados y no existen archivos privados adicionales dentro de `data/`. El esquema mantiene el contrato fuera de `backend/` y `frontend/`, con una lista explícita de acciones y sin acoplar la implementación de las capas.
