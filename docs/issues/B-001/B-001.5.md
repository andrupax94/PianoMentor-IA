# [B-001.5] Configurar variables de entorno y `.gitignore`

## Descripción

Definir la configuración externa sin versionar secretos ni depender de valores específicos de una máquina.

## Archivos esperados

```text
.env.example
.gitignore
```

## Variables iniciales

```text
API_HOST
API_PORT
CORS_ORIGINS
NEXT_PUBLIC_API_URL
NEXT_PUBLIC_WS_URL
GROQ_API_KEY
LANGCHAIN_API_KEY
LANGCHAIN_TRACING_V2
```

## Criterios de aceptación

- [x] `.env` está excluido de Git.
- [x] `.env.example` existe y no contiene secretos reales.
- [x] Las variables de backend y frontend están documentadas.
- [x] Las URLs HTTP y WebSocket están separadas.
- [x] Los nombres son consistentes con el código.
- [x] No hay claves API en el código fuente.
- [x] Los logs no imprimen secretos.

## Dependencias

Depende de **B-001.1**. Puede coordinarse con **B-001.2** y **B-001.3**.

## Evidencia de cierre

Validación ejecutada desde la raíz del repositorio:

```text
Variables esperadas en .env.example:
OK: API_HOST
OK: API_PORT
OK: CORS_ORIGINS
OK: NEXT_PUBLIC_API_URL
OK: NEXT_PUBLIC_WS_URL
OK: GROQ_API_KEY
OK: LANGCHAIN_API_KEY
OK: LANGCHAIN_TRACING_V2

git check-ignore -v .env
→ .gitignore:2:.env .env

git ls-files --error-unmatch .env
→ el archivo no está versionado

git grep -n -I -E "gsk_...|sk-...|github_pat_..."
→ sin coincidencias

from piano_mentor.config import settings
→ SETTINGS IMPORT OK
→ API_HOST=0.0.0.0
→ API_PORT=8000

python -m compileall -q backend/src backend/tests
→ compilación correcta

python -m pytest -q backend/tests -x
→ 4 passed
```

Las claves sensibles permanecen vacías en `.env.example` y los valores reales solo se mantienen en el `.env` local ignorado.
