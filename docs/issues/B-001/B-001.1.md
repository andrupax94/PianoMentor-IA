# [B-001.1] Crear la estructura base de carpetas

## Descripción

Crear la estructura inicial del monorepo de acuerdo con `ARCHITECTURE.md`, separando código, pruebas, datos y contratos.

## Carpetas esperadas

```text
backend/src/
backend/tests/
frontend/src/
frontend/src/components/
frontend/src/lib/
shared/schemas/
data/midi/
data/uploads/
data/sessions/
.github_projects/
```

## Criterios de aceptación

- [x] Existen las carpetas principales `backend`, `frontend`, `shared`, `data` y `.github_projects`.
- [x] Backend y frontend están separados.
- [x] Las pruebas están separadas del código de producción.
- [x] Los datos no se almacenan dentro de `src/`.
- [x] La estructura coincide con el árbol MVP de `ARCHITECTURE.md`.
- [x] Las carpetas vacías necesarias se conservan mediante `.gitkeep` o archivos equivalentes.
- [x] No existen carpetas duplicadas con responsabilidades ambiguas.

## Dependencias

Ninguna. Esta Sub-issue debe completarse antes de organizar los módulos posteriores.

## Evidencia

Mostrar el árbol relevante del repositorio y explicar cualquier diferencia respecto a `ARCHITECTURE.md`.
