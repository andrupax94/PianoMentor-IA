# [U-004] Cambiar la carga lazy de sonidos del piano a una carga simple con barra de progreso

**Estado:** implementado (2026-10-31), pendiente aceptación auditiva del usuario. Sampler con `loadAll()` + barra de progreso en la UI + Cache API + MAX_DECODED_BUFFERS=512 (evita poda) + carga al montar (evita deadlock).

**GitHub:** issue [#85](https://github.com/andrupax94/PianoMentor-IA/issues/85).

## Descripción

El sampler de piano (B-007.5) carga las muestras de forma perezosa por capas (Tier 0 HQ para la ventana visible, Tier 1 LQ para el resto), con precarga en segundo plano. Mientras no están decodificadas, suena la voz de reserva, lo que produce saltos de timbre en los primeros golpes y una UX confusa (el usuario no sabe cuándo el piano "está listo").

U-004 cambia a una **carga simple**: todas las muestras se descargan de una vez, con una **barra de progreso** visible, para que el usuario vea el avance y el piano suene con muestra real desde el primer golpe disponible.

## Alcance

- **Sampler (`piano-samples.ts`):** añade `onProgress` callback y método `loadAll()` que descarga todas las muestras (todos los tiers) secuencialmente reportando progreso 0→1. Mantiene `preload(tier)` por compatibilidad.
- **Hook (`usePlayback.ts`):** usa `loadAll()` en lugar de `preload("hq")`/`preload("lq")`; expone `soundProgress` (0..1) y `soundReady` en el handle.
- **UI (`PlaybackArea.tsx`):** barra de progreso visible mientras `soundProgress < 1`.
- **Compatibilidad:** `PolySynth` y el contrato de la API no cambian; `playback-engine.ts`, `Keyboard.tsx` siguen igual.

## Criterios de aceptación

- [x] El sampler limita las voces y descarga todas las muestras con progreso reportado.
- [x] La barra de progreso es visible en la UI mientras carga.
- [x] `npm test -- --run` y `npm run build` en verde.
- [ ] Aceptación auditiva final por el usuario.

## Límites conocidos

- La carga simple descarga más datos de una vez; en conexiones lentas puede tardar. Se acepta en el MVP.
- No cambia el timbre ni la voz de reserva; solo el momento de carga.
