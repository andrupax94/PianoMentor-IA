# [B-007.1] Teclado SVG inline con ventana visible y mapeo pitch→id

**Estado:** implementado y cubierto por tests; pendiente de verificación manual y aceptación.

## Descripción

Renderizar el asset `frontend/assets/piano_virtual_88_pressed.svg` como SVG inline en React (no como `<img>`, para poder tocar cada tecla) y añadir el mapeo exacto de pitch MIDI a id de tecla más una ventana visible con estado (C1–C6 por defecto, como en el diseño). Sin resaltados todavía: solo el teclado dibujado y direccionable.

## Alcance

- Importar el SVG como JSX inline (con la herramienta que se decida en la implementación: componente generado o `dangerouslySetInnerHTML` + query por `data-key-id`; documentar la elegida).
- Función pura `pitchToKeyId(pitch)` (`nombres[pitch % 12] + octava`, ej. 60→`c4`) con tests en vitest para bordes (21→`a0`, 108→`c8`).
- Verificar que los 88 ids del asset son únicos y cubren A0–C8 (52 blancas + 36 negras).
- Estado de ventana visible (`fromKey`/`toKey`, por defecto C1–C6) que recorta qué teclas se muestran; el resto del SVG no se renderiza o se oculta, y el `viewBox` se recorta a la ventana para que las teclas ocupen el ancho.
- Documentar el mecanismo de pressed del asset: los gradientes `whitePressed`/`blackPressed` existen pero nada los conmuta; el encendido se hará cambiando `fill` por código en B-007.2.
- Tests: mapeo en bordes y centro, unicidad de ids y recorte de ventana.

## Criterios de aceptación

- [x] El teclado se dibuja desde el asset inline y cada tecla es direccionable por su `data-key-id`.
- [x] `pitchToKeyId` es exacto en 21, 60, 108 y en los 88 valores intermedios (test de barrido).
- [x] La ventana por defecto muestra C1–C6 como en el diseño y es cambiable por estado.
- [x] `npm test -- --run` pasa y `npm run build` compila.

## Dependencias

No depende de **B-006.1–B-006.3** (no necesita la partitura para dibujarse). Habilita a **B-007.2** (resaltado) y vive dentro de `PianoStage/Keyboard/` de **B-006.4**.

## Evidencia esperada

- Teclado dibujado desde el asset, función de mapeo con tests y captura de la ventana C1–C6.
