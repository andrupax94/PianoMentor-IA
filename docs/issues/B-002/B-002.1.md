# [B-002.1] Definir el contrato de piezas MIDI

## Descripción

Definir los modelos y respuestas mínimas que representarán una pieza MIDI cargada, sin implementar todavía el parsing completo ni el endpoint final de B-003.

## Alcance

- Definir un identificador estable de pieza.
- Definir nombre de archivo original y nombre almacenado.
- Definir tamaño, extensión y ruta lógica sin exponer rutas privadas innecesarias.
- Definir metadatos iniciales opcionales: número de tracks, duración aproximada, tempo y número de notas.
- Mantener los modelos independientes de FastAPI cuando sea posible.

## Criterios de aceptación

- [x] Existe un modelo tipado para una pieza almacenada.
- [x] Existe un modelo de respuesta para la carga inicial.
- [x] Los campos obligatorios y opcionales están documentados.
- [x] El contrato no contiene rutas absolutas del equipo del usuario.
- [x] El contrato puede ser utilizado por B-003 sin redefinirse.
- [x] Existen tests de serialización y validación básica.

## Dependencias

Depende de **B-002**. Es prerequisito de **B-002.4** y **B-003**.

## Evidencia esperada

Modelos tipados, ejemplo de respuesta y tests de contrato.
