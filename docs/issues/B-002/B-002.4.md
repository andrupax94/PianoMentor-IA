# [B-002.4] Preparar fixtures y pruebas para la carga MIDI

## Descripción

Crear la base de pruebas que permita implementar B-003 con confianza y comprobar que el healthcheck existente no se rompe.

## Alcance

- Crear uno o más fixtures MIDI mínimos y válidos.
- Crear casos inválidos: extensión no admitida, archivo vacío, contenido no MIDI y exceso de tamaño.
- Probar contrato, almacenamiento y validadores juntos.
- Documentar la respuesta esperada de `POST /api/v1/pieces`.
- Mantener una prueba de regresión para `/health`.

## Criterios de aceptación

- [x] Existe al menos un fixture MIDI válido creado por el proyecto o con licencia compatible.
- [x] Los fixtures inválidos no contienen datos privados.
- [x] Hay tests para carga válida y rechazos esperados.
- [x] Hay una prueba de regresión del healthcheck.
- [x] Los tests se ejecutan sin depender de rutas absolutas.
- [x] La estructura de pruebas permite añadir casos de parsing en B-003 y B-005.
- [x] La evidencia deja claro qué queda para B-003.

## Dependencias

Depende de **B-002.1**, **B-002.2** y **B-002.3**. Es la última subissue de B-002 y habilita **B-003**.

## Evidencia esperada

Fixtures versionados, tests ejecutados y contrato de integración documentado.
