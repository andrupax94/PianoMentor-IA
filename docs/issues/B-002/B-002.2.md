# [B-002.2] Preparar almacenamiento local de piezas MIDI

## Descripción

Crear la abstracción mínima de almacenamiento y una implementación local basada en filesystem para guardar piezas MIDI sin acoplar el endpoint a rutas concretas.

## Alcance

- Definir una interfaz o protocolo de almacenamiento.
- Implementar el adaptador de filesystem local.
- Obtener la raíz desde `MIDI_STORAGE_PATH`.
- Crear la carpeta de destino cuando sea necesario.
- Guardar y recuperar archivos mediante identificadores estables.
- Evitar sobrescrituras accidentales.

## Criterios de aceptación

- [x] El caso de uso depende de una abstracción, no de `open()` directamente.
- [x] La implementación local usa `MIDI_STORAGE_PATH`.
- [x] La carpeta se crea de forma segura cuando no existe.
- [x] Guardar y recuperar un archivo funciona con tests temporales.
- [x] Los archivos no se guardan dentro de `backend/src/`.
- [x] El adaptador no ejecuta contenido del archivo cargado.
- [x] B-003 puede reutilizarlo para persistir una carga válida.

## Dependencias

Depende de **B-002**. Puede coordinarse con **B-002.1** y es prerequisito de **B-002.4** y **B-003**.

## Evidencia esperada

Contrato de almacenamiento, adaptador local y tests con un directorio temporal.
