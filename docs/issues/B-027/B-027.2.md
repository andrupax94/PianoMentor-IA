# [B-027.2] Crear el catálogo de piezas con metadatos y licencias

## Descripción

Crear un catálogo JSON (o similar) que contenga los metadatos de las 15 piezas del corpus, incluyendo procedencia y licencia.

## Alcance

- Crear `data/midi/catalog.json` o similar.
- Cada entrada incluye: id, título, compositor, licencia, fuente, dificultad, duración aproximada.
- Los archivos MIDI se ubican en `data/midi/corpus/`.
- Validar que cada archivo del catálogo existe y es procesable.

## Criterios de aceptación

- [x] El catálogo está versionado en el repositorio (`data/midi/catalog.json`).
- [x] Cada entrada tiene todos los metadatos requeridos (id, título, compositor, opus, archivo, fuente, licencia, dificultad, duración, notas).
- [x] Los archivos MIDI referenciados existen en el repositorio (`data/midi/corpus/`, 15/15 válidos con mido).
- [x] Existe un test que valida la integridad del catálogo (`backend/tests/test_catalog.py`, 5 tests en verde).

## Dependencias

Depende de **B-027.1**. Es prerequisito de **B-027.3**.

## Evidencia esperada

- Catálogo JSON versionado.
- Script de validación del catálogo.
