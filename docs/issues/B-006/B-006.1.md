# [B-006.1] Servir las notas reproducibles de una pieza

**Estado:** implementado y cubierto por tests; pendiente de verificación manual y aceptación.

## Descripción

Exponer desde el backend la partitura lista para reproducir: las notas normalizadas de B-005 de una pieza persistida, ordenadas por instante de inicio, con una ventana opcional por segundos (`from_s`/`to_s`) que anticipe la selección de secciones de B-008. Es la única llamada de red que necesita la reproducción; a partir de aquí el navegador trabaja con datos locales.

## Alcance

- Nuevo endpoint de solo lectura, p. ej. `GET /api/v1/pieces/{piece_id}/notes`, que resuelve la pieza por id (corpus o subida, reutilizando la dedup de B-028).
- Lee el MIDI del filesystem (`stored_filename`), lo normaliza con el motor de B-005 y devuelve las notas ordenadas por `start_s` (con orden estable ante empates): pitch, inicio, duración, velocity, canal y track.
- Parámetros opcionales `from_s`/`to_s` que recortan la ventana sin reordenar ni reinterpretar nada.
- La respuesta incluye el tempo inicial, la duración total y los metadatos ya conocidos de la pieza para que el front no tenga que pedirlos por separado.
- La pieza inexistente responde 404 con código estable; un MIDI ilegible responde 400 con el mismo código de B-005.4.
- Tests de backend: orden estable, ventana de sección, pieza inexistente y corpus real.

## Criterios de aceptación

- [x] Pedir las notas de una pieza del corpus devuelve la secuencia completa ordenada por tiempo, idéntica entre llamadas.
- [x] `from_s`/`to_s` recortan la ventana sin alterar el orden ni los tiempos de las notas incluidas.
- [x] La respuesta trae tempo inicial y duración total coherentes con `PieceMetadata`.
- [x] Un id inexistente devuelve 404 con código estable, sin trazas expuestas.
- [x] `python -m pytest -q` pasa y el healthcheck continúa en verde.

## Dependencias

Depende de **B-005** (normalización y tempo) y de **B-003** (pieza persistida con `stored_filename`). Habilita a **B-006.2**, **B-006.3** y, más adelante, a **B-007**, **B-008** y **B-013**.
