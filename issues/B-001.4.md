# [B-001.4] Crear carpetas de datos y esquemas compartidos

## Descripción

Separar los datos temporales del código y preparar los contratos compartidos entre backend y frontend.

## Estructura esperada

```text
data/midi/
data/uploads/
data/sessions/
shared/schemas/
shared/schemas/action.schema.json
```

## Criterios de aceptación

- [ ] Los archivos MIDI tienen una ubicación definida.
- [ ] Las cargas temporales están separadas.
- [ ] Las sesiones de práctica tienen una carpeta propia.
- [ ] Los esquemas están fuera de `backend/` y `frontend/`.
- [ ] `action.schema.json` es JSON válido.
- [ ] Python puede leer el esquema usando UTF-8.
- [ ] No se almacenan archivos privados dentro del repositorio.
- [ ] El contrato permite evolucionar sin acoplar directamente las capas.

## Dependencias

Depende de **B-001.1**. Puede coordinarse con **B-001.2** y **B-001.3**.

## Validación

```powershell
python -c "import json; json.load(open('shared/schemas/action.schema.json', encoding='utf-8')); print('JSON OK')"
```
