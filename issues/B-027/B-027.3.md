# [B-027.3] Integrar el catálogo en el frontend como piezas seleccionables

## Descripción

Permitir que el usuario seleccione una pieza del catálogo directamente desde el frontend, sin necesidad de cargar un archivo manualmente.

## Alcance

- Crear una sección "Piezas incluidas" o similar en el frontend.
- Mostrar las piezas del catálogo con título, compositor y dificultad.
- Al seleccionar una pieza, iniciar una sesión de práctica con esa pieza.
- Mantener la opción de carga manual como alternativa.

## Criterios de aceptación

- [ ] El frontend muestra las piezas del catálogo.
- [ ] El usuario puede seleccionar una pieza y empezar a practicar.
- [ ] La pieza seleccionada se carga correctamente en el backend.
- [ ] La opción de carga manual sigue funcionando.

## Dependencias

Depende de **B-027.2**, **B-003** y **B-004**.

## Evidencia esperada

- Interfaz de selección de piezas.
- Flujo de práctica iniciado desde el catálogo.
