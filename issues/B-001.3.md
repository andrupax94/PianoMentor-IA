# [B-001.3] Preparar la configuración inicial del frontend

## Descripción

Dejar preparado el frontend Next.js con TypeScript y una estructura para componentes reutilizables y clientes HTTP/WebSocket.

## Archivos esperados

```text
frontend/package.json
frontend/Dockerfile
frontend/next.config.ts
frontend/tsconfig.json
frontend/src/app/layout.tsx
frontend/src/app/page.tsx
frontend/src/app/globals.css
frontend/src/components/
frontend/src/lib/
```

## Criterios de aceptación

- [ ] El proyecto utiliza Next.js y TypeScript.
- [ ] `package.json` contiene scripts de desarrollo y build.
- [ ] El frontend puede instalar sus dependencias.
- [ ] La página principal carga correctamente.
- [ ] TypeScript está configurado.
- [ ] Existe una ubicación para componentes reutilizables.
- [ ] Existe una ubicación para clientes HTTP y WebSocket.
- [ ] El Dockerfile del frontend puede construirse.
- [ ] La aplicación responde en `http://localhost:3000` cuando se arranca.

## Dependencias

Depende de **B-001.1**.

## Evidencia

Ejecutar la instalación o build disponible y documentar la URL local de comprobación.
