# [B-001.5] Configurar variables de entorno y `.gitignore`

## Descripción

Definir la configuración externa sin versionar secretos ni depender de valores específicos de una máquina.

## Archivos esperados

```text
.env.example
.gitignore
```

## Variables iniciales

```text
API_HOST
API_PORT
CORS_ORIGINS
NEXT_PUBLIC_API_URL
NEXT_PUBLIC_WS_URL
GROQ_API_KEY
LANGCHAIN_API_KEY
LANGCHAIN_TRACING_V2
```

## Criterios de aceptación

- [ ] `.env` está excluido de Git.
- [ ] `.env.example` existe y no contiene secretos reales.
- [ ] Las variables de backend y frontend están documentadas.
- [ ] Las URLs HTTP y WebSocket están separadas.
- [ ] Los nombres son consistentes con el código.
- [ ] No hay claves API en el código fuente.
- [ ] Los logs no imprimen secretos.

## Dependencias

Depende de **B-001.1**. Puede coordinarse con **B-001.2** y **B-001.3**.

## Evidencia

Mostrar una comprobación de Git de los archivos ignorados sin revelar el contenido de `.env`.
