# [B-001] Crear y validar la estructura monorepo

## Resumen

Preparar la base reproducible de PianoMentor AI para que backend, frontend, datos, contratos compartidos y Docker evolucionen de forma modular, sin mezclar responsabilidades.

## Objetivo

Dejar una estructura MVP coherente con [`ARCHITECTURE.md`](../../ARCHITECTURE.md), preparada para desarrollar FastAPI, Next.js/TypeScript, procesamiento MIDI y despliegue mediante Docker Compose.

- [B-001.2 — Preparar la configuración inicial del backend](B-001.2.md)
- [B-001.3 — Preparar la configuración inicial del frontend](B-001.3.md)
- [B-001.4 — Crear carpetas de datos y esquemas compartidos](B-001.4.md)

- [B-001.8 — Validar la estructura completa](B-001.8.md)

## Criterio de aceptación de la Issue principal

- [ ] Todas las Sub-issues están completadas.
- [ ] La estructura coincide con `ARCHITECTURE.md`.
- [ ] Backend y frontend pueden construirse.
- [ ] Docker Compose puede iniciar los servicios.
- [ ] El frontend y el backend responden localmente.
- [ ] Las variables de entorno están documentadas sin secretos.
- [ ] Los esquemas compartidos son válidos.
- [ ] La documentación permite repetir el arranque en otro entorno.

## Fuera de alcance

- Parsing MIDI avanzado, compases y polifonía.
- Reproducción musical y evaluación de interpretaciones.
- WebSocket funcional de práctica.
- Integración con el LLM o la máquina de estados pedagógica.
- Despliegue público, vídeo demo y publicación en LinkedIn.

## Evidencia esperada

- Salida correcta de `docker compose config`.
- Build exitoso de backend y frontend.
- Capturas o logs de los servicios arrancados.
- Ejecución de las validaciones indicadas en las Sub-issues.
