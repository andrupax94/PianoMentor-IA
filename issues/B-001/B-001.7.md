# [B-001.7] Añadir documentación mínima de instalación y arranque

## Descripción

Documentar el procedimiento para que otra persona pueda preparar y arrancar el proyecto sin explicaciones adicionales.

## Contenido mínimo

1. Requisitos previos.
2. Preparación de `.env` desde `.env.example`.
3. Construcción de imágenes.
4. Arranque de servicios.
5. URLs locales.
6. Detención de servicios.
7. Validaciones básicas.

## Criterios de aceptación

- [ ] Los pasos parten desde la raíz del repositorio.
- [ ] Se explica cómo crear `.env` sin incluir secretos.
- [ ] Se documentan `docker compose build`, `up` y `down`.
- [ ] Se documentan las URLs locales.
- [ ] Se explica cómo ejecutar las validaciones básicas.
- [ ] Otra persona puede repetir el arranque siguiendo únicamente la documentación.
- [ ] No se duplica información que corresponde a `PLAN.md` o `ARCHITECTURE.md`.

## Dependencias

Depende de **B-001.1** a **B-001.6**.

## Evidencia

Realizar una prueba siguiendo la documentación desde una terminal limpia o documentar qué parte no pudo probarse.
