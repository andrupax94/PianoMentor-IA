# [B-001.8] Validar la estructura completa

## Descripción

Comprobar que la estructura inicial, backend, frontend, datos y Docker funcionan conjuntamente.

## Criterios de aceptación

- [ ] `docker compose config` finaliza correctamente.
- [ ] La imagen del backend se construye.
- [ ] La imagen del frontend se construye.
- [ ] Los contenedores arrancan correctamente.
- [ ] El frontend responde en `http://localhost:3000`.
- [ ] El backend responde en `http://localhost:8000`.
- [ ] No existen errores de importación Python.
- [ ] No existen errores de compilación TypeScript.
- [ ] Los directorios de datos están disponibles.
- [ ] El frontend puede comunicarse con el backend.
- [ ] Los tests iniciales pueden ejecutarse.
- [ ] No quedan rutas incorrectas ni referencias a archivos inexistentes.

## Dependencias

Depende de **B-001.2** a **B-001.7**.

## Validación sugerida

```powershell
docker compose config
docker compose build
docker compose up
python -m compileall backend/src backend/tests
```

Si ya existe el endpoint:

```powershell
curl http://localhost:8000/health
```

## Evidencia

Adjuntar logs o capturas de los servicios y anotar cualquier limitación reproducible.
