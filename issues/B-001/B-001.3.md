# [B-001.3] Preparar la configuración inicial del frontend

## Descripción

Dejar preparado el frontend Next.js con TypeScript y una estructura para componentes reutilizables y clientes HTTP/WebSocket.

## Archivos esperados

```text
frontend/package.json
frontend/Dockerfile
frontend/next.config.ts
frontend/tsconfig.json
frontend/src/app/layout.tsx
frontend/src/app/page.tsx
frontend/src/app/globals.css
frontend/src/components/
frontend/src/lib/
```

## Criterios de aceptación

- [x] El proyecto utiliza Next.js y TypeScript.
- [x] `package.json` contiene scripts de desarrollo y build.
- [x] El frontend puede instalar sus dependencias.
- [x] La página principal carga correctamente.
- [x] TypeScript está configurado.
- [x] Existe una ubicación para componentes reutilizables.
- [x] Existe una ubicación para clientes HTTP y WebSocket.
- [x] El Dockerfile del frontend contiene el contexto y el comando necesarios para construir y arrancar la aplicación.
- [x] La aplicación responde en `http://localhost:3000` cuando se arranca.

## Dependencias

Depende de **B-001.1**.

## Evidencia de cierre

Validación ejecutada desde `frontend/`:

```text
npm run build
→ compilación Next.js completada correctamente
→ TypeScript completado correctamente
→ rutas generadas: /, /_not-found y /practice/[sessionId]
```

La página se arrancó localmente con:

```powershell
npm run start -- -p 3000
```

Y se confirmó visualmente que carga correctamente en:

```text
http://localhost:3000
```

La carpeta `frontend/src/lib/` existe como ubicación base para los clientes HTTP y WebSocket, que se implementarán posteriormente en B-004 y B-012.
