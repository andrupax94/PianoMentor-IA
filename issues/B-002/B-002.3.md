# [B-002.3] Definir límites y seguridad de cargas MIDI

## Descripción

Establecer las reglas de validación previa que B-003 aplicará antes de almacenar un archivo MIDI.

## Alcance

- Aceptar únicamente `.mid` y `.midi` sin depender solo del nombre del archivo.
- Definir un límite inicial de tamaño configurable o documentado.
- Normalizar nombres sin permitir path traversal.
- Generar nombres internos que eviten colisiones y sobrescrituras.
- Rechazar archivos vacíos o claramente inválidos antes de persistirlos.
- Definir errores estables para que FastAPI pueda traducirlos a respuestas HTTP.

## Criterios de aceptación

- [ ] Las extensiones aceptadas están centralizadas.
- [ ] El límite de tamaño está definido y probado.
- [ ] Se rechazan nombres con rutas, traversal o caracteres no permitidos.
- [ ] El nombre original se conserva solo como metadato seguro.
- [ ] Las reglas no dependen de un proveedor externo.
- [ ] Existen tests para extensión, tamaño, nombre y colisión.
- [ ] B-003 puede usar las reglas sin duplicarlas en el endpoint.

## Dependencias

Depende de **B-002**. Puede coordinarse con **B-002.1** y **B-002.2**. Es prerequisito de **B-002.4** y **B-003**.

## Evidencia esperada

Validador reutilizable, límites documentados y tests de casos válidos e inválidos.
