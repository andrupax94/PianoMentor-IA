# [B-001.6] Preparar Docker Compose y contextos de build

## Descripción

Permitir construir y ejecutar backend y frontend desde la raíz del proyecto con Docker Compose.

## Archivos esperados

```text
docker-compose.yml
backend/Dockerfile
frontend/Dockerfile
```

## Servicios iniciales

```text
backend  → puerto 8000
frontend → puerto 3000
```

## Criterios de aceptación

- [ ] `docker-compose.yml` tiene sintaxis válida.
- [ ] Backend y frontend tienen servicios definidos.
- [ ] Los contextos de build son correctos.
- [ ] Los Dockerfiles no copian archivos fuera de su contexto.
- [ ] Los puertos están correctamente expuestos.
- [ ] Los volúmenes de datos están definidos cuando corresponda.
- [ ] Los servicios comparten una red de Compose.
- [ ] El frontend puede resolver la configuración del backend.
- [ ] No se copian secretos dentro de las imágenes.

## Dependencias

Depende de **B-001.2**, **B-001.3**, **B-001.4** y **B-001.5**.

## Validación

```powershell
docker compose config
docker compose build
```
