# [B-003.3] Cargar catalog.json del corpus en SQLite

**Estado:** completada (2026-10-16). El cargador idempotente vive en `backend/src/piano_mentor/catalog.py`; se lanza con `python -m piano_mentor.catalog` y, desde B-027.4, se siembra solo en `GET /api/v1/pieces` cuando la base no tiene corpus.

## Descripción

Cargar las 15 piezas de `data/midi/catalog.json` en SQLite para que el corpus esté disponible sin subidas manuales.

## Alcance

- Crear un script o comando (p. ej. `scripts/load_catalog.py` o función en backend) que lea `catalog.json`.
- Verificar que cada archivo referenciado existe antes de insertarlo.
- Insertar o actualizar (idempotente) los metadatos en la tabla `pieces`.
- Registrar licencia, fuente y dificultad de cada pieza.
- No generar embeddings todavía: la columna vectorial queda nula hasta que B-005/B-013 definan las features.
- No modificar el formato de `catalog.json` (propiedad de B-027.2).

## Implementado

- El cargador es `load_catalog()` en `backend/src/piano_mentor/catalog.py`, invocable como `python -m piano_mentor.catalog` (o desde código). **No** se usó `scripts/load_catalog.py`.
- `_record()` valida primero que existe cada MIDI referenciado (`CatalogError` si falta) y solo entonces escribe; el formato de `catalog.json` no se toca.
- `upsert_piece` hace la carga **idempotente** por `id` (una segunda ejecución no duplica). Registra licencia, `source_url`, dificultad y `cover`, calcula `content_hash` y marca `source='corpus'` para que subir un MIDI idéntico reutilice la fila del catálogo.
- El tempo (BPM inicial) se calcula del propio MIDI con el motor determinista (`_tempo_bpm`).
- **B-027.4** añadió `ensure_catalog_loaded()`: `GET /api/v1/pieces` siembra el corpus si la tabla no tiene ninguna pieza suya, así que un arranque limpio ya sirve la Library sin el comando manual. El comando se mantiene para forzar o recargar.
- Tests: `test_catalog_load.py` (15 piezas, idempotencia, licencia/fuente registradas, MIDI existentes y fallo sin escribir si falta un archivo) y `test_catalog.py` (integridad del `catalog.json` versionado).

## Criterios de aceptación

- [x] Las 15 piezas del catálogo existen como filas en `pieces`.
- [x] La carga es idempotente (segunda ejecución no duplica).
- [x] Los archivos MIDI referenciados existen en `data/midi/corpus/` (se verifica antes de escribir).
- [x] Licencia y fuente quedan registradas por pieza.
- [x] Existe un test que valida la carga contra el catálogo versionado.
- [x] La carga funciona en local y en Docker (misma ruta `data/midi/catalog.json` y misma base `DATABASE_URL`).

## Dependencias

Depende de **B-003.1** y **B-027.2** (formato de `catalog.json`). Habilita **B-027.3**. B-027.4 reutiliza el cargador para sembrar el corpus al listar.
