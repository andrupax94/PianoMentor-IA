# [B-003.1] Instalar SQLite + sqlite-vec y esquema base de piezas

## Descripción

Instalar la extensión sqlite-vec, crear `database.py` con una conexión reutilizable y definir el esquema base para piezas y vectores.

## Alcance

- Añadir la dependencia sqlite-vec al backend (y a la imagen Docker).
- Cargar la extensión al abrir la conexión SQLite.
- Reutilizar `DATABASE_URL` de la configuración existente (`config.py`).
- Crear `backend/src/piano_mentor/database.py` con funciones de conexión y creación de esquema.
- Tabla `pieces`: `id`, `filename`, `stored_filename`, `size_bytes`, `extension`, `tracks`, `duration_s`, `notes_count`, `created_at`.
- Tabla `piece_vectors`: `piece_id` (FK a `pieces`), `embedding` (vector sqlite-vec, nullable hasta que B-005/B-013 definan las features).
- Documentar el esquema (migración mínima o script de init versionado).

## Criterios de aceptación

- [ ] La extensión sqlite-vec se carga sin errores en local y en Docker.
- [ ] Existe una función de conexión reutilizable por otros módulos (p. ej. B-012).
- [ ] Las tablas `pieces` y `piece_vectors` se crean de forma reproducible.
- [ ] Los vectores son opcionales: una pieza puede existir sin embedding.
- [ ] Existen tests de conexión, carga de la extensión y creación del esquema.
- [ ] No se crean tablas de sesiones (reservadas para B-012).

## Dependencias

Depende de **B-003** y **B-002**. Es prerequisito de **B-003.2** y **B-003.3**.

## Evidencia esperada

- Dependencia instalada, `database.py`, esquema documentado y tests de conexión.
