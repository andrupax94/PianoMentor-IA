# [B-004.2] Conectar la pantalla de carga y mostrar los metadatos devueltos

## Descripción

Conectar el componente `MidiUploader.tsx` (hoy placeholder sin lógica) al cliente HTTP y mostrar al usuario los metadatos que el backend persistió y devolvió.

## Alcance

- Reemplazar el placeholder de `MidiUploader.tsx` por la carga real vía `uploadPiece`.
- Validación orientativa en cliente: extensión `.mid`/`.midi` y tamaño antes de subir (la autoridad sigue siendo el backend).
- Estados visibles: archivo seleccionado, subiendo, listo y error.
- Mostrar metadatos devueltos: filename, tamaño, extensión, y tracks/duración/nº de notas cuando no sean nulos.
- Mantener el resto de la página (`SessionStatus`, `PianoKeyboard`) sin cambios.
- No duplicar en el frontend reglas de validación del backend: la validación cliente es solo UX.

## Criterios de aceptación

- [x] Un MIDI válido seleccionado se sube y sus metadatos aparecen en la pantalla.
- [x] El estado "subiendo" impide envíos repetidos mientras hay una carga en curso.
- [x] Los campos nulos de metadatos no se muestran como ceros ni como basura.
- [x] La validación cliente rechaza extensiones no permitidas antes de llamar al backend.
- [x] El backend sigue siendo el único que valida el contenido real del archivo.
- [x] `npm run build` compila sin errores y el healthcheck del backend sigue en verde.

## Dependencias

Depende de **B-004.1**. Es prerequisito de **B-004.3** y **B-027.3**.

## Evidencia esperada

- `MidiUploader.tsx` conectado y captura del flujo subir → ver metadatos.
