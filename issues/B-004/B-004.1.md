# [B-004.1] Crear el cliente HTTP tipado del frontend

## Descripción

Crear `frontend/src/lib/api-client.ts` como único punto de llamadas REST hacia FastAPI, con los tipos de TypeScript que reflejan los contratos Pydantic ya existentes.

## Alcance

- Crear `frontend/src/lib/api-client.ts` (hoy solo existe un `.gitkeep` en `frontend/src/lib/`).
- Tipar `PieceResponse`, `PieceMetadata` y el error `{code, message}` de B-002.1/B-003.2 en TypeScript.
- Exponer `uploadPiece(file)` sobre `POST /api/v1/pieces` y `getHealth()` sobre `GET /health`.
- Usar la URL base desde `NEXT_PUBLIC_API_URL` (ya definida en `docker-compose.yml`), sin rutas absolutas incrustadas.
- Mapear respuestas 4xx/5xx a un error tipado con `code` y `message`, sin lanzar excepciones sin capturar al llamador.
- No usar `fetch` fuera de este módulo.

## Criterios de aceptación

- [ ] `api-client.ts` compila con TypeScript en modo estricto.
- [ ] Los tipos coinciden con `schemas.py` del backend (mismos campos y nulabilidad).
- [ ] `uploadPiece` envía el archivo como `multipart/form-data` con el campo `file`.
- [ ] Un 400 del backend se entrega al llamador con su `code` y `message` originales.
- [ ] Ningún componente accede a la API sin pasar por este cliente.
- [ ] `npm run build` termina sin errores.

## Dependencias

Depende de **B-004**. Es prerequisito de **B-004.2** y será reutilizado por **B-012**.

## Evidencia esperada

- Módulo `api-client.ts` con tipos exportados y verificación de compilación.
