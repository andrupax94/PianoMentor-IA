# [B-012.6] Groq + salida estructurada

**Estado:** pendiente; documentos inicializados, sin implementar.

## Descripción

Conectar proveedor LLM (Groq) con salida JSON estructurada para proponer acciones; mantener `MockProvider` determinista como fallback.

## Alcance

- Interfaz `LLMProvider` con `propose_action(state) -> ActionProposal`.
- `MockProvider`: devuelve acción fija o basada en reglas simples (para tests/CI).
- `GroqProvider`: llama API Groq con prompt + JSON schema (action + params), parse valida contra whitelist.
- `AgentService` inyecta proveedor vía config (`settings.llm_provider`).
- Fallback: si Groq falla/timeout → `MockProvider` (sin romper flujo).
- Secrets: `GROQ_API_KEY` en `.env` / Docker secret.
- Tests: `MockProvider` en CI; `GroqProvider` marcado `@pytest.mark.integration` (manual).

## Criterios de aceptación

- [ ] `MockProvider` funciona en CI sin secrets.
- [ ] `GroqProvider` devuelve JSON válido contra schema.
- [ ] Fallback automático si Groq falla.
- [ ] Acción propuesta pasa por `agent.validate()` antes de ejecutar.
- [ ] `python -m pytest -q` pasa (sin Groq).

Depende de **B-012.4** (validación). Habilita **B-012.7** (acompañamiento).
