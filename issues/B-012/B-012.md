## Objetivo

Vertical completa del **agente pedagógico**: sesión + WebSocket → evaluación determinista → máquina de estados → acciones validadas → demo + devolución control → (opcional) Groq + acompañamiento.  
Todo comparte `agent.py`, `practice.py`, endpoints `/sessions/*` y WS `/ws/sessions/{id}`.

## Sub-issues

| Sub-issue | Título | Qué hace | Depende de |
|---|---|---|---|
| B-012.1 | Sesión + WebSocket real | Cablear `practice.py`: persistencia sesión, estado (`idle/playing/paused`), eventos MIDI entrantes, WS push/pull | B-011 (teclado PC ✓) |
| B-012.2 | Evaluación determinista | Comparar notas esperadas vs recibidas (pitch, timing, velocity), tolerancia configurable, scoring, detectar omitidas/extras/incorrectas, acordes básicos | B-012.1, B-009 (acordes) |
| B-012.3 | Máquina de estados + reglas | Estados: `OBSERVING → EVALUATING → DECIDE_ACTION → {WAITING, GIVE_HINT, SLOW_DOWN, DEMONSTRATE, ACCOMPANY, RETURN_CONTROL}`; reglas deterministas por error/timing/espera | B-012.2 |
| B-012.4 | Validación de acciones | `agent.validate(action)`: whitelist, límites tempo/compases/repeticiones/duración/timeout, pieza/sesión | B-012.3 |
| B-012.5 | Demo + devolución control | Implementar `demonstrate` (reproduce sección a tempo reducido) y `return_control` (auto-devuelve a estudiante) | B-012.4 |
| B-012.6 | Groq + salida estructurada | Proveedor LLM intercambiable (`MockProvider`/`GroqProvider`), JSON schema para acciones, fallback determinista si falla | B-012.4 |
| B-012.7 | Acompañamiento (si tiempo) | Acción `accompany`: IA toca una parte (ej. mano izq) mientras estudiante otra; requiere sync WS preciso | B-012.5, B-019 |

## Criterios de aceptación (padre)

- [ ] Sesión se crea, persiste, recibe eventos por WS y expone estado.
- [ ] Evaluación produce scoring determinista sin LLM.
- [ ] Máquina de estados transita y selecciona acción válida.
- [ ] Acciones rechazadas si violan límites.
- [ ] Demo visible, duración limitada, control vuelve al estudiante.
- [ ] Funciona con `MockProvider` (Groq opcional).
- [ ] Tests: transiciones, validaciones, evaluación exacta/adelantada/retrasada/omitida/extras/acordes.
