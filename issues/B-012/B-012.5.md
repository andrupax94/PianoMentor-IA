# [B-012.5] Demo + devolución control

**Estado:** pendiente; documentos inicializados, sin implementar.

## Descripción

Implementar acciones `demonstrate` (IA reproduce sección a tempo reducido) y `return_control` (devuelve control al estudiante automáticamente).

## Alcance

- `demonstrate`: recibe `{start_measure, end_measure, tempo_factor}` → usa `play_section` (B-008.2) para reproducir ventana; envía por WS `agent_action: {type: "demonstrate", ...}`; front muestra indicador "IA demostrando".
- `return_control`: WS `agent_action: {type: "return_control"}`; front quita indicador, habilita teclado.
- Auto-`return_control` tras N compases (configurable, default 4) o al terminar sección demostrada.
- Duración limitada: max 16 compases por demo.
- Tests: demo se reproduce, WS notifica, control vuelve, límites respetados.

## Criterios de aceptación

- [ ] `demonstrate` reproduce sección a tempo reducido vía `play_section`.
- [ ] WS notifica inicio/fin de demo.
- [ ] `return_control` automático tras N compases o fin de sección.
- [ ] Front muestra estado "IA demostrando" y bloquea input.
- [ ] `python -m pytest -q` + `npm test -- --run` pasan.
