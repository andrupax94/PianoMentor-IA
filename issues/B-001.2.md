# [B-001.2] Preparar la configuración inicial del backend

## Descripción

Dejar preparado el backend Python/FastAPI para crecer por módulos y poder ejecutarse localmente o dentro de Docker.

## Archivos esperados

```text
backend/pyproject.toml
backend/Dockerfile
backend/src/piano_mentor/__init__.py
backend/src/piano_mentor/main.py
backend/tests/
```

## Criterios de aceptación

- [ ] El paquete `piano_mentor` puede importarse correctamente.
- [ ] Las dependencias están declaradas en `pyproject.toml`.
- [ ] FastAPI y Uvicorn están configurados.
- [ ] Existe un punto de entrada claro para la aplicación.
- [ ] Existe una carpeta preparada para tests.
- [ ] El backend no depende directamente del frontend.
- [ ] El Dockerfile puede construir una imagen del backend.
- [ ] La sintaxis pasa `python -m compileall backend/src backend/tests`.

## Dependencias

Depende de **B-001.1**.

## Evidencia

Ejecutar la compilación Python y documentar el comando de arranque previsto.
