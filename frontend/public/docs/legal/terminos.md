# Términos y condiciones del servicio

**Versión 1.0** — publicada el 2026-11-12. PianoMentor AI es un servicio de práctica de piano asistida por inteligencia artificial.

## 1. Uso del servicio

El servicio se ofrece para fines educativos y de práctica personal. No debe usarse para actividades ilícitas ni para distribuir material protegido por derechos de autor sin permiso.

## 2. Cuenta de usuario

El usuario es responsable de mantener la confidencialidad de sus credenciales. La cuenta puede crearse con Google (OAuth) o con correo y contraseña; en este último caso el correo debe verificarse mediante el enlace enviado por email.

## 3. Piezas subidas y corpus

Las piezas MIDI que el usuario sube son de su responsabilidad. El usuario declara tener derecho a usarlas. El servicio puede almacenarlas para ofrecer la práctica y el análisis.

## 4. Exención de responsabilidad docente

Las sugerencias del mentor son orientativas y no sustituyen a un profesor de piano humano. El servicio no garantiza resultados de aprendizaje.

## 5. Cambios del servicio

El servicio puede cambiar o interrumpirse. Los cambios relevantes en estos términos se publicarán en esta página con una nueva versión y fecha.
